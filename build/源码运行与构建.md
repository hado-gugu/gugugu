# 咕顾谷源码运行与构建

咕顾谷是《明日方舟》卫戍协议的配队、商店提醒和干员速查工具。使用步骤与反馈方式见项目根目录的《使用前请先阅读.txt》。

## Windows

在 Windows 64 位上安装 CPython 3.12，然后在项目目录打开 PowerShell。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-tested.txt
.\.venv\Scripts\python.exe app.py
```

生成便携版本时执行以下命令。程序和使用说明位于 `dist/Gugugu101/`。

```powershell
.\build.ps1 -SkipQaLauncher
```

## macOS Beta

在 Apple Silicon Mac 上使用 macOS 14.4 或更新版本和原生 arm64 CPython 3.12。从终端执行 `bash run-macos.command`。首次启动会下载依赖。根据系统提示给终端授权屏幕录制，再重新打开程序。配队和设置保存在 `~/Library/Application Support/Gugugu/`。

安装 Xcode 命令行工具后，可用 `bash build-macos.sh` 构建本地试用的 `.app`。Mac 上的捕获、识别和提醒显示仍待实机验证。

## 随源码提供的数据

- `catalog.json` 保存干员、装备和盟约目录。
- `assets/operator-reference.json` 保存干员速查的效果标签和触发时机。感谢海马提供的标签整理（小红书id：11543288921）。
- `assets/` 还包含界面、商店定位和教程所用的资源。《明日方舟》相关素材及数据的权利归各自权利人所有。
- `build/` 中的 Python 脚本用于维护目录、标签和教程素材。更新目录与标签时需自行准备客户端目录数据或干员表，运行程序直接使用仓库内的 JSON。
